Desarrollar una página web no consiste únicamente en escribir código: también hay que pensar en las personas que la usarán y en quienes tendrán que mantenerla. Aplicar algunas buenas prácticas desde el principio ayuda a conseguir sitios más comprensibles y fiables.

Usa HTML semántico

Los elementos HTML deben describir el significado del contenido. Por ejemplo, utiliza encabezados para organizar secciones, listas para enumerar elementos y enlaces para navegar a otros recursos. Una estructura semántica facilita la lectura y la navegación con tecnologías de asistencia.

La guía de HTML de MDN explica cómo estructurar documentos web.

Cuida la accesibilidad

Escribe textos de enlace descriptivos, mantén un orden lógico de encabezados y proporciona alternativas textuales para las imágenes. Así, más personas podrán comprender y utilizar el contenido.

Comprueba la navegación con teclado

Recorre los enlaces y controles con el teclado para comprobar que puedes llegar a ellos y entender dónde se encuentra el foco.

Puedes consultar las pautas de accesibilidad de W3C para aprender más.

Escribe código claro y mantenible

Indenta el código de forma consistente, utiliza nombres significativos y evita elementos o atributos que no sean necesarios. Una estructura ordenada hace más sencillo revisar y actualizar el proyecto.

Prueba los enlaces y el contenido

Antes de publicar, recorre todas las páginas y comprueba que los enlaces internos llegan a su destino y que los externos usan direcciones válidas. También conviene revisar el sitio en distintos tamaños de pantalla.
