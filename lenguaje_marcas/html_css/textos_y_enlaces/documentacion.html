Introducción

WeatherAPI proporciona información meteorológica en tiempo real y pronósticos para ubicaciones específicas. Sus endpoints permiten integrar estos datos en aplicaciones y servicios.

Consultar documentación oficial

Autenticación

Para utilizar WeatherAPI, debes obtener una clave de API y enviarla con tus solicitudes para autenticar el acceso.

Consulta nuestra Política de seguridad para obtener más información.

Endpoint de usuarios

Permite consultar la información de un usuario registrado y administrar los datos asociados a su cuenta.

Endpoint de ciudades

Permite consultar las ciudades disponibles, su ubicación geográfica y los datos meteorológicos asociados.
